2. Example: Importing a Class
Let’s say you have synth.ck:


// synth.ck
public class MySynth {
    SinOsc osc => dac;
    440 => osc.freq;
    
    fun void start() {
        1 => osc.gain;
    }
    
    fun void stop() {
        0 => osc.gain;
    }
}



Now in main.ck, you can do:

chuck
